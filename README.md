# Terminal City — a storybook of the daily cycle

The storybook website of the album *Terminal City*: one chapter per element of the city's daily cycle, each with a
title, an illustration, a short story, the element's rule and chant, its place on the map, and (as they are
finished) the track and its music video.

The site is static and **generated, never hand-edited**: the pages are built from the Terminal City field guide by
a small Python builder; `stories/stories.json` holds the retellings, `VERSION` and `CHANGELOG.md` say what changed.
Every page's colophon names the site version, build date and the field-guide draft it was built from.

Terminal City is an original fictional mythology inspired by Vancouver's geography, weather, wildlife,
infrastructure, art, and electronic music. It makes no claim to historical, Indigenous, or religious tradition.
Real places are used as settings; the operating system layered on them is invented.
